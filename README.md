# Rogue-like-game

Консольная игра в жанре **Rogue-like**, разработанная в рамках курсового проекта.

## О проекте

Игра, в которой игрок исследует случайно генерируемые уровни, сражается с противниками и постепенно развивает своего персонажа.

Основная задача игрока — проходить уровни, становиться сильнее и достичь конечной цели игры.

## Основные возможности

* случайная генерация уровней;
* исследование игрового мира;
* сражения с противниками;
* развитие персонажа;
* консольный интерфейс.
