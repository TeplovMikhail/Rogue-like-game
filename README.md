# Rogue-like-game

Консольная игра в жанре Rogue-like, разработанная в рамках курсового проекта.

## Описание проекта

Игра, в которой игрок исследует случайно генерируемые уровни, сражается с противниками и постепенно развивает своего персонажа.

Основная задача игрока — проходить уровни, становиться сильнее и достичь конечной цели игры.

## Лабораторная работа № 2

**Тема:** классы, композиция и агрегация объектов.

### Реализованные классы

- **`Enemy`** — противник. Хранит имя, здоровье и урон. Поддерживает получение урона, вывод информации и проверку состояния.
- **`Room`** — игровая комната. Может содержать ссылку на противника и позволяет выводить информацию о нём и атаковать его.
- **`Level`** — игровой уровень. Содержит комнату и выводит информацию об уровне.

### Основные возможности

- Использование классов с закрытыми полями и открытыми методами.
- Использование конструкторов и деструкторов.
- Проверка корректности передаваемого урона.
- Реализация композиции: уровень содержит комнату.
- Реализация агрегации: комната взаимодействует с отдельно созданным противником.
- Демонстрация времени жизни объектов и автоматического уничтожения объектов.

## Сборка и запуск

Перейдите в папку с файлами лабораторной работы и выполните:

```bash
g++ main.cpp enemy.cpp room.cpp level.cpp -o roguelike.exe
```

Запуск в Git Bash:

```bash
./roguelike.exe
```
